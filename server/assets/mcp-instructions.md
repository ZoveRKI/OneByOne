OneByOne 把一次代码改动拆成有顺序的讲解步骤，逐步播放每一步的 diff 和讲解。用户想看懂这次改了什么、要求讲解或说明改动时使用，通常在改完代码之后：

1. 调用 `get_changes`，`repo` 填项目目录的绝对路径。结果是带编号的改动清单，末尾附有写法要求。
2. 按写法要求编排步骤，调用 `show_walkthrough` 提交。步骤只引用改动块编号，不要复制代码；结合你在这次对话里对改动意图的了解来写讲解。
3. 结果里列出没讲到的改动块或数据问题时，修改后再调用一次 `show_walkthrough`。

支持 MCP Apps 的客户端会在对话里显示播放器；不能显示时，把结果里的播放页面路径告诉用户，用浏览器打开。
